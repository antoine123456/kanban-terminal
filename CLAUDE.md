# kanban-terminal

Le code : `kanban_terminal/` (Textual) — `app.py` le tableau, `model.py` le fichier, `gantt.py`
le Gantt, `tidy.py` kanban-tidy, `snippets.py`, `junit.py` / `unittest_xml.py` la vue tests.
Tests : `.venv/bin/python -m unittest discover -s tests -q`. README et aide (`?`, texte dans
`app.py`) suivent chaque changement de touche ou de format.
